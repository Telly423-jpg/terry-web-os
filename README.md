# terry-web-os
Welcome to my personal virtual desktop system running entirely in the browser, hosted on **GitHub Pages**!
## ✨ Features (功能特色)

- **🖥️ Desktop Environment**: A clean window management system supporting dragging, minimizing, closing, and window focus layers.
- **🌍 Multi-language Support**: Easily switch between **English**, **Traditional Chinese (繁體中文)**, and **Simplified Chinese (简体中文)** right from the top bar.
- **🎨 Custom Wallpapers & Presets**: Choose from 4 stunning gradient presets or upload your own custom wallpaper image directly from your computer.
- **📝 Built-in Notepad & File Manager**: Create, edit, and save `.txt` files directly on the desktop (persisted via `localStorage`), or upload your own local text files.
- **📄 Terry's Resume**: Includes a pre-loaded resume/bio file (`Resume.txt`) on the desktop.
- **🌐 In-app Web Browser**: Browse embeddable websites and explore bookmarks within a windowed browser frame.
- **⏰ Live Clock Widget & Timezones**: Real-time clock widget with automatic local time detection or manual timezone configuration.

---

## 🚀 Quick Start (快速開始)

Since this is a pure frontend project built in a **single `index.html` file**, deploying it to GitHub Pages takes less than a minute:

1. Create a new public repository on GitHub.
2. Upload the `index.html` file into your repository.
3. Go to your repository **Settings > Pages**.
4. Under **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
5. Visit your generated GitHub Pages link and enjoy your virtual desktop!
